# Core Rules — Whiteout (가제)

모든 값은 *(provisional)*: 데이터로 분리하고 첫 플레이 후 조정한다.
상위 문서: `design/game-brief.md`

## 1. 런 구조
- 하루 180초 = 낮 120초 + 밤 60초. 하루를 넘기면 아침에 증강 3택 1.
- 부품 3개: 2·4·6일차 이후 하나씩 맵에 등장.
- 부품 3개로 무전기 수리 → 수리한 날부터 2일 버티면 구조(승리).
- 수리 마감 없음. 자원 고갈로 자연스럽게 한계가 온다.
- 실패: 체력 0 → 런 종료, 처음부터 다시 시작. 증강은 사라진다.
- 목표 한 판 길이: 20~30분 (약 8일 + 구조 대기 2일).

## 2. 허들 (모두 0~100)
| 허들 | 변화 | 30 미만 | 0일 때 |
|---|---|---|---|
| 체온 | 환경 온도 × 0.1 / 초 | 이동속도 -25% | 체력 -2 / 초 |
| 허기 | -0.4 / 초, 식량 1개 +30 | 채집속도 -30%, 체온 감소 ×1.5 | 체력 -1 / 초 |
| 체력 | 체온·허기 모두 60 이상이면 +0.5 / 초 | — | 사망 |

## 3. 환경 온도 (시간과 무관)
```
환경 온도(°C) = 기본 기온 + 날씨 보정 + 장소 보정 + 증강 보정
초당 체온 변화 = 환경 온도 × 0.1   (허기 30 미만이면 감소량만 ×1.5)
```

| 요인 | 값 |
|---|---|
| 기본 기온 | -10°C |
| 날씨 | 맑음 0 / 눈 -5 / 눈보라 -15 (시야 감소) / 한파 -25 |
| 장소 | 숲 0 / 탁 트인 설원 -5 / 은신처 +10 / 모닥불 반경 4m +35 |

- 날씨는 날짜와 무관하게 무작위. 연속 제한은 플레이 후 판단.
- 밤은 시야만 좁아진다 (온도에 영향 없음).

## 4. 자원과 모닥불
- 자원 4종: 땔감, 식량, 불씨, 부품. 한 번 쓰면 다시 생기지 않음.
- 맵 배치: 땔감 35 / 식량 28 / 불씨 3 / 부품 3 (필요량 대비 약 15% 여유).
- 땔감 1개 = 60초 연소, 모닥불에 최대 5개.
- 불이 꺼지면 불씨 1 + 땔감 2로 다시 피움.
- 시작: 불 켜진 상태, 불씨 1개 지급, 시작 지점 근처에 첫날 분량 보장.
- 운반: 기본 6칸, 자원 1개 = 1칸.

## 5. 맵
- 지형 고정 1개, 자원·부품은 매 판 후보 지점 중 무작위.
- 크기: 모닥불에서 반경 약 200m. 리소스 제작하며 확정.
- 이동속도: 초당 4m.

## 6. 늑대
- 밤에만 모닥불 반경 밖에 1~2마리, 불빛 안으로 들어오지 않음, 아침에 사라짐.
- 체력: 3번 맞으면 처치. 물기: 체력 -15, 1.5초 간격.
- 플레이어 공격: 근접 1.5m, 0.6초 간격, 마우스 방향.

## 7. 증강 (16개, 중복 없음, 3택 1, 리롤 없음)
★ = 규칙 변경형 (증강별 코드 필요)

| 분야 | 증강 | 효과 |
|---|---|---|
| 보온 | 두꺼운 외투 | 체감 온도 +4°C |
| | 방풍 망토 | 날씨 보정 절반 |
| | 털모자 | 탁 트인 설원 보정 무시 |
| | ★ 마지막 온기 | 체온 0 이후 15초간 체력 감소 없음 |
| 모닥불 | 마른 장작 요령 | 땔감 연소 시간 +40% |
| | 큰 불 | 온기 반경 4m → 6m |
| | ★ 불씨 상자 | 원하는 곳에 작은 불 1회 |
| | ★ 숯불 | 불이 꺼져도 30초간 반경 2m 온기 |
| 채집·운반 | 빠른 손 | 채집 속도 +30% |
| | 큰 배낭 | 운반량 +3칸 |
| | 알뜰한 채집 | 채집 시 20% 확률로 1개 추가 |
| | ★ 썰매 | 운반량 ×2, 이동속도 -10% |

| | 밝은 눈 | 밤·눈보라 시야 +30% |
