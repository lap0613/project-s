# Core Rules — Whiteout (가제)

모든 값은 *(provisional)*: 데이터로 분리하고 첫 플레이 후 조정한다.
상위 문서: `design/game-brief.md`

## 1. 런 구조
- 하루 180초 = 낮 120초 + 밤 60초. 하루를 넘기면 아침에 증강 3택 1.
- 증강을 고르는 동안 게임은 정지한다 (체온·허기·늑대 모두 멈춤).
- 플레이어는 맵 중심에서 0~60m 링 안의 무작위 지점에서 시작한다. 무전기는 없다.
- 구조 신호기 부품 3개(안테나·배터리·송신기): 2·4·6일차 이후 하나씩 맵에 등장, 맵에서 줍기만 한다 (위치는 §5).
- **구조 신호기:** B로 신호기 틀을 원하는 위치에 설치하고(나무 4 + 금속 조각 2, 임시값), E로 부품을 하나씩 장착한다.
  한 판에 1개만 설치, 설치 후 옮길 수 없음, 늑대가 부술 수 없음.
- 부품 3개를 모두 장착하면 완성. 완성된 신호기에 E로 구조를 요청하면 그 시점부터 2일(게임 시간 360초) 타이머가 시작되고,
  HUD에 구조까지 남은 시간이 표시된다. 타이머가 끝나면 구조(승리). 위치 제약 없음. 증강 선택 중에는 타이머도 정지.
- 요청 마감 없음. 자원 고갈로 자연스럽게 한계가 온다.
- 실패: 체력 0 → 런 종료, 처음부터 다시 시작. 증강은 사라진다.
- 사망·구조 후: 결과 화면(생존 일수, 고른 증강, 사망 원인: 동사·아사·늑대) + 다시 하기.
- 목표 한 판 길이: 20~30분 (약 8일 + 구조 대기 2일).

## 2. 허들 (모두 0~100)
| 허들 | 변화 | 30 미만 | 0일 때 |
|---|---|---|---|
| 체온 | 환경 온도 × 0.1 / 초 | 이동속도 -25% | 체력 -2 / 초 |
| 허기 | -0.4 / 초, 식량별 회복량은 items.md | 채집속도 -30%, 체온 감소 ×1.5 | 체력 -1 / 초 |
| 체력 | 체온·허기 모두 60 이상이면 +0.5 / 초 | — | 사망 |

- 은신처 안에서 E로 휴식하는 동안: 체력 회복 조건이 체온·허기 30 이상으로 낮아지고, 회복량 3배(+1.5 / 초).

## 3. 환경 온도 (시간과 무관)
```
환경 온도(°C) = 기본 기온 + 날씨 보정 + 거리 링 보정 + 모닥불 온기 + 증강 보정
초당 체온 변화 = 환경 온도 × 0.1   (허기 30 미만이면 감소량만 ×1.5)
```

| 요인 | 값 |
|---|---|
| 기본 기온 | -10°C |
| 날씨 | 맑음 0 / 눈 -5 / 눈보라 -15 / 한파 -25 |
| 거리 링 (맵 중심 기준) | 0~60m +5 / 60~130m -5 / 130~200m -15 → 맑은 날 체감 -5 / -15 / -25°C |
| 모닥불 온기 | 켜진 모닥불 반경 4m 안 +35. 여러 개가 겹쳐도 가장 따뜻한 1개만 |

- 장소 구역(숲·설원 등)은 두지 않는다. 장소에 따른 온도는 맵 중심과의 거리(링)로만 정한다.
- 은신처는 온기를 주지 않는다 (휴식·회복 전용, §2).
- 날씨: 아침마다 1회 결정되고 하루 동안 유지. 확률 맑음 40 / 눈 30 / 눈보라 20 / 한파 10 (%).
  날짜와 무관한 무작위. 3일치를 미리 뽑아 오늘·내일·모레를 정확하게 예보한다. 연속 제한은 플레이 후 판단.
- 시야 (온도와 무관): 밤에는 플레이어 주변 12m와 모닥불 빛만 보인다.
  눈보라는 안개로 약 15m 너머가 흐려진다. 둘이 겹치면 더 좁은 쪽.

## 4. 아이템과 설치
- 아이템 종류·목록·제작·가방·시작 소지품·맵 배치량: `design/quick-specs/items.md`.
- 맵의 아이템은 한 번 쓰면 다시 생기지 않음.
- 채집: E키 1초 누르기. 채집하는 동안 이동 불가.
- 불 없이 시작한다. 시작 위치 근처에 첫날 분량의 나무·식량을 보장한다.
- **모닥불 설치:** 나무 3 + 부싯깃 1 (부싯돌 필요). 설치 후 나무를 넣어야 켜진다.
  나무 1개 = 60초 연소, 최대 5개. 개수 제한 없음.
- **재점화:** 꺼진 모닥불은 부싯깃 1 + 나무 2로 다시 피운다 (부싯돌 필요).
- **은신처 설치:** 나무 6. 반경 3m, 휴식(§2)과 제작(items.md) 공간, 온기 없음, 늑대는 막지 못함. 개수 제한 없음.
- **요리:** 켜진 모닥불에서 날고기를 E 3초로 굽는다.

## 5. 맵
- 지형 고정 1개, 자원·부품은 매 판 후보 지점 중 무작위.
- 크기: 맵 중심에서 반경 약 200m, 거리 링 3개(§3). 리소스 제작하며 확정.
- 시작 위치: 맵 중심에서 0~60m 링 안의 무작위 지점.
- 부품 위치: 부품 1(2일차 이후)은 가운데 링(60~130m), 부품 2·3(4·6일차 이후)은 바깥 링(130~200m)의 후보 지점 중 무작위.
- 이동속도: 초당 4m.

## 6. 늑대
모든 수치 *(provisional)*, 플레이 후 조정. 단위: 거리 m, 속도 m/s (Unity 1유닛 = 1m). 그리드 판정 없음.

- 맵 생성 시 늑대 무리 중심지(서식지)를 스폰한다. 무리 2~3개, 무리당 2마리 (임시값).
  중심지는 플레이어가 스폰되는 안쪽 링(0~60m)의 바로 바깥인 가운데 링(60~130m) 안에 무작위로 배치한다.
- 처치한 늑대는 다시 생기지 않는다 (원칙).
- **낮:** 무리 중심지 근처 짧은 반경에서 쉬거나(idle) 천천히 걷는다. 배회 상태의 '낮 모드'로 처리한다(반경·속도만 다름).
  낮에도 플레이어가 가까이 오거나 늑대를 공격하면 추적·공격한다.
- **밤:** 아래 표대로 움직인다. 상태 5단계, 길찾기는 NavMesh.
- **아침:** 추적 중이던 늑대는 아침이 와도 추적·공격을 계속한다. 추적이 끝나면(포기) 무리 중심지로 돌아가 낮 모드가 된다.

| 상태 | 규칙 |
|---|---|
| 배회 | 밤: 무리 중심지 주변을 2 m/s로 돌아다닌다 · 낮 모드: 중심지에서 반경 3m 안에서 idle 또는 1 m/s로 걷기 |
| 감지 | 밤: 플레이어가 12m 안 (눈보라일 때 8m) · 낮: 플레이어가 4m 안에 오거나 늑대가 공격받으면. 시야가 가려진 플레이어는 감지하지 못한다 |
| 추적 | 4.5 m/s로 쫓는다 (플레이어 기본 4 m/s보다 약간 빠름) |
| 공격 | 1.5m 안에서 물기: 체력 -15, 쿨다운 1.5초 |
| 포기·후퇴 | 25m 이상 멀어지거나 8초 동안 놓치면 추적을 멈추고 무리 중심지로 돌아간다(밤이면 배회, 낮이면 낮 모드). 놓침 = 플레이어가 현재 감지 거리 밖이거나, 거리 안이어도 장애물(나무·바위·지형)에 시야가 가려진 상태. 낮/밤이 바뀌어도 추적은 이 조건으로만 끝난다. 불빛에 닿으면 즉시 후퇴 |

- 불빛 범위: 켜진 모닥불은 온기 반경과 같다(기본 4m, 큰 불 증강 6m). 횃불은 4m. 늑대는 이 범위 안으로 들어오지 않는다.
- 늑대 체력: 3번 맞으면 처치. 처치 시 드롭은 `items.md`.
- 플레이어 공격: 근접 1.5m, 0.6초 간격, 마우스 방향.

**시야 가림:** 나무·바위·지형만 시야를 가린다. 플레이어가 설치한 구조물(모닥불·은신처·구조 신호기)과 바닥의 아이템은 가리지 않는다.
감지와 놓침 모두 같은 가림 기준을 쓴다.

**아이디어 (미확정)**
- 무리 중심지를 핵심 아이템(구조 신호기 부품 등)과 묶어서 스폰

## 7. 증강 (16개, 중복 없음, 3택 1, 리롤 없음)
★ = 규칙 변경형 (증강별 코드 필요)

**중첩 규칙** (증강·장비 공통, 공식은 `code-structure.md` §5):
- 같은 스탯의 % 효과는 합연산: 모두 더한 뒤 한 번만 곱한다. 예: 설피 +15%와 썰매 -10% → 이동속도 ×1.05.
- 곱하는 값의 하한은 ×0.1 (임시값).
- 확률 효과(알뜰한 채집 20% 등)는 예외: 같은 확률끼리 더하고 100%가 상한.
- 고정값 효과(두꺼운 외투 +4°C 등)는 % 계산 전에 더한다.

| 분야 | 증강 | 효과 |
|---|---|---|
| 보온 | 두꺼운 외투 | 체감 온도 +4°C |
| | 방풍 망토 | 날씨 보정 절반 |
| | 털모자 | 거리 링 보정이 음수일 때 절반 |
| | ★ 마지막 온기 | 체온 0 이후 15초간 체력 감소 없음 |
| 모닥불 | 마른 장작 요령 | 나무 연소 시간 +40% |
| | 큰 불 | 모든 모닥불 온기 반경 4m → 6m |
| | ★ 휴대용 화로 | 하루 1회, 30초 동안 플레이어 주변 1.5m에 +10°C |
| | ★ 숯불 | 불이 꺼져도 30초간 반경 2m 온기 |
| 채집·운반 | 빠른 손 | 채집 속도 +30% |
| | 큰 배낭 | 운반량 +3칸 |
| | 알뜰한 채집 | 채집 시 20% 확률로 1개 추가 |
| | ★ 썰매 | 운반량 ×2, 이동속도 -10% |
| 이동·탐색 | 설피 | 이동속도 +15% |
| | 밝은 눈 | 밤·눈보라 시야 +30% |
| | 지도 감각 | 주변 15m 자원 위치 표시 |
| | ★ 귀환 본능 | 하루 1회 가장 가까운 켜진 모닥불로 즉시 귀환. 켜진 불이 없으면 사용 불가 |

나중에 추가할 분야: 사냥, 제작 품질.
