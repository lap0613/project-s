# 증강 방향 안 — Whiteout (가제)

> **제안, 지영 확인 전 미확정.** 이 문서는 선택지를 비교하는 제안서다. 여기 적힌 수치·새 증강은 규칙이 아니다.
> 확정되면 `design/quick-specs/core-rules.md` §7과 `production/epics/whiteout/story-005-augments.md`를 고친다. 그 전까지 두 문서가 우선이다.

상위 문서: `design/game-brief.md` (Hooks, Kill condition) · 현재 규칙: `design/quick-specs/core-rules.md` §7
배경: 영상 "게임의 기획이 튼튼한지 검증하는 5가지 질문" 분석(2026-11-13)의 제안 5번. 지영 결정으로 제안서 작성.

## 1. 왜 다시 보는가

브리프의 훅은 "증강이 공격력이 아닌 **버티는 방식**을 바꾼다 (불 옆을 지키는 빌드 vs 멀리 돌아다니는 빌드)"이다 *(guessed)*.
지금 증강 16개가 이 훅을 받쳐 주는지 보면 네 가지가 약하다.

1. **한 판에 절반 넘게 갖게 된다.** 한 판은 약 8일 + 구조 대기 2일(core-rules §1)이라 아침마다 1개씩 약 9개를 고른다.
   16개 중 9개(56%)를 갖게 되어 판마다 가진 증강이 비슷해진다. 리롤도 없다.
2. **규칙을 바꾸는 증강이 적다.** 16개 중 11개가 수치 보정이고 ★ 규칙형은 5개다.
3. **대가가 있는 증강이 1개뿐이다** (썰매: 운반량 ×2, 이동속도 -10%). 나머지는 고르면 무조건 이득이라 '선택'이 아니라 '수집'에 가깝다.
4. **증강끼리 맞물리는 조합이 없다.** 중첩 규칙(% 합연산)은 있지만 둘을 같이 가졌을 때 생기는 효과가 없다.

## 2. 현재 16개 분류

분류 기준: 불 근처에 머무를수록 이득이면 '불 지키는 빌드', 불에서 멀어질수록 이득이면 '돌아다니는 빌드', 어디서나 같으면 '공통'.

|---|---|---|---|---|
| 마른 장작 요령 | 모닥불 | 나무 연소 시간 +40% | 수치 | 불 지키는 |
| 큰 불 | 모닥불 | 온기 반경 4m → 6m | 수치 | 불 지키는 |
| ★ 숯불 | 모닥불 | 불이 꺼져도 30초간 반경 2m 온기 | 규칙 | 불 지키는 |
| 털모자 | 보온 | 거리 링 보정이 음수일 때 절반 | 수치 | 돌아다니는 |
| ★ 휴대용 화로 | 모닥불 | 하루 1회, 30초 동안 주변 1.5m에 +10°C | 규칙 | 돌아다니는 |
| 큰 배낭 | 채집·운반 | 운반량 +3칸 | 수치 | 돌아다니는 |

| 지도 감각 | 이동·탐색 | 주변 15m 자원 위치 표시 | 수치 | 돌아다니는 |
| ★ 귀환 본능 | 이동·탐색 | 하루 1회 가장 가까운 켜진 모닥불로 귀환 | 규칙 | 돌아다니는 |

| 빠른 손 | 채집·운반 | 채집 속도 +30% | 수치 | 공통 |
| 알뜰한 채집 | 채집·운반 | 채집 시 20% 확률로 1개 추가 | 수치 | 공통 |

| 빌드 | 개수 | ★ | 대가 있음 |
|---|---|---|---|
| 불 지키는 | 3 | 1 | 0 |
| 돌아다니는 | 8 | 3 | 1 |
| 공통 | 5 | 1 | 0 |
| 합계 | 16 | 5 | 1 |

**읽히는 것:** 불 지키는 빌드가 3개뿐이라 한쪽 빌드로 성립하지 않는다. 지금 구성은 사실상 '돌아다니는 빌드 + 공통'이다.
또 자원이 다시 생기지 않아 결국 멀리 나가야 하므로(브리프 Challenge) 불 지키는 빌드는 규칙상으로도 불리하다.
불 지키는 빌드를 살리려면 "덜 나가도 되게 하는" 증강(연료·식량 효율)이 필요하다.

### A. 다듬기 — 풀은 그대로, 대가와 조합만 추가
- 대가 추가 예 (기존 수치형 3개):
  - 큰 불: 온기 반경 4m → 6m, **나무 연소 시간 -20%**
  - 설피: 이동속도 +15%, **채집 속도 -10%**
  - 큰 배낭: 운반량 +3칸, **이동속도 -5%**
- 조합 2쌍:
  - 큰 불 + 숯불 → 숯불의 온기 반경도 2m → 3m
  - 지도 감각 + 알뜰한 채집 → 표시된 자원에서 추가 확률 20% → 35%

### B. 넓히기 — 풀 24, 불 지키는 빌드를 성립시킨다
새 증강 8개 예시 (이름·수치는 모두 예시):

| 새 증강 | 빌드 | 종류 | 효과 예시 |
|---|---|---|---|
| ★ 모닥불지기 | 불 지키는 | 규칙·대가 | 켜진 모닥불 온기 반경 안에서는 허기 감소 절반. 반경 밖에서는 체온 감소 ×1.2 |
| ★ 불씨 나르기 | 불 지키는 | 규칙 | 켜진 모닥불에서 불씨를 들고 60초 안에 다른 모닥불에 대면 부싯깃 없이 점화 |
| ★ 따뜻한 잠자리 | 불 지키는 | 규칙 | 은신처가 켜진 모닥불 온기 반경 안에 있으면 휴식 회복 ×1.5 |
| 화덕 | 불 지키는 | 수치 | 요리 시간 절반, 구운 고기 허기 +10 |
| 통나무 불 | 불 지키는 | 수치·대가 | 연료 최대 5개 → 8개, 나무 연소 시간 -15% |
| ★ 추위에 익은 몸 | 돌아다니는 | 규칙·대가 | 바깥 링의 거리 보정을 가운데 링 값으로 취급. 모닥불 온기 +35 → +25 |
| 가벼운 걸음 | 돌아다니는 | 수치·대가 | 이동속도 +25%, 운반량 -2칸 |
| 굶주린 집중 | 공통 | 수치·대가 | 허기 30 미만의 채집 속도 불이익이 없어진다. 허기 감소 +20% |

- 대가 6개 = 썰매 + 새 5개(모닥불지기, 통나무 불, 추위에 익은 몸, 가벼운 걸음, 굶주린 집중).
- 조합 4쌍 = A의 2쌍 + 아래 2쌍:
  - 마른 장작 요령 + 통나무 불 → 통나무 불의 연소 시간 불이익이 사라진다
  - 귀환 본능 + 휴대용 화로 → 귀환 직후 휴대용 화로가 한 번 더 충전된다
- 리롤은 넣지 않는다. 풀이 넓어져 판마다 달라지는 효과는 이미 얻고, '주어진 3개 중에 고른다'는 긴장을 지킨다.
  넣는다면 한 판 1회(무료)가 가장 작다.

### C. 다시 짜기 — 풀 32, 세트 효과와 리롤
- B의 8개에 더해 새 증강 8개. 예시:
  - ★ 불의 고리(불 지키는): 켜진 모닥불 2개가 10m 안에 있으면 둘 사이 전체가 온기 범위
  - ★ 설원의 눈(돌아다니는): 눈보라 중에도 시야가 줄지 않는다. 맑은 날 시야 -20%
  - ★ 비상 식량(공통): 허기가 0이 되는 순간 한 판 1회 허기 +40
- 같은 빌드 증강 3개를 모으면 세트 효과(예: 불 지키는 3개 → 모든 모닥불 온기 +5°C).
- 리롤: 선택 화면에서 나무 2개를 내고 3개를 다시 뽑는다(한 번의 선택에 1회).
- 등급·세트·리롤 표시가 선택 화면(ui-plan §11 S8)에 추가된다.

## 4. 추천: B (넓히기), 리롤 없음

1. **훅을 실제로 받친다.** 불 지키는 빌드가 3개 → 8개가 되어 두 빌드가 비슷한 무게로 성립한다.
2. **9/16 문제를 줄인다.** 한 판에 풀의 38%만 갖게 되어 판마다 구성이 달라진다. 풀 확대는 데이터 추가가 대부분이다
   (수치형은 에셋만, ★은 효과 클래스 1개 + 에셋: code-structure §6).
3. **범위가 감당할 만하다.** 새 ★ 코드는 4개다. story-005의 구조(카탈로그·3택 1·수정자)는 그대로이고 개수와 AC만 바뀐다.
4. **기존 결정과 충돌하지 않는다.** 리롤을 넣지 않으므로 브리프 Out of scope를 그대로 둔다.
5. **Kill condition 확인이 늦어지지 않는다.** C는 증강을 다 만들기 전에는 "3일차 이후가 반복인가"를 볼 수 없다.

순서 제안: B의 24개를 한 번에 만들지 않는다. story-005에서 기존 16개 + 새 4개(★ 2, 대가 2)로 먼저 플레이하고,
반응을 본 뒤 나머지 4개와 조합을 넣는다.
